# AI Instructions & Repository Rules

Concise operating guide for AI coding agents and developers working in **Nodepad**.

## 1. Repository Layout

- `backend/` — FastAPI + SQLAlchemy 2.0 + Alembic + PostgreSQL 18 (`uv` workspace member)
- `frontend/` — React 19 + TypeScript + Vite 7 + TanStack Router/Query (`bun` workspace member)
- `scripts/` — Cross-stack scripts (`generate-client.sh`, `test.sh`, `test-local.sh`)
- `compose.yml`, `compose.override.yml`, `compose.traefik.yml`, `compose.coolify.yml` — Docker Compose stacks

## 3. Coding Rules & Boundaries

### Backend (`backend/specs.md` is authoritative)
- **Layering**:
  - `backend/app/api/routes/` — HTTP boundary only (request validation, auth deps, `HTTPException`, delegates to `crud/`).
  - `backend/app/services/` — Pure domain logic (`lists.py` LIS, `nodes.py` path/level). **Never** import `Session`, run DB queries, or touch HTTP objects.
  - `backend/app/crud/` — Persistence and DB-specific operations (fractional indexing, `ltree` cascading updates).
  - `backend/app/models/` — SQLAlchemy 2.0 `Mapped` / `mapped_column` models.
  - `backend/app/schemas/` — Pydantic v2 schemas (`ConfigDict(from_attributes=True)`).
- **Standards**:
  - Strict typing required (`mypy` strict mode). No `Any` unless justified.
  - No `print()` statements (`ruff` `T201` enabled). Use `logging`.
  - No synchronous blocking I/O in `async` routes.
  - PostgreSQL-specific (`ltree`, `FOR UPDATE`, `Numeric(30, 15)`); do not write DB-agnostic workarounds that break `ltree`.

### Frontend
- **Do NOT hand-edit `frontend/src/client/`**. It is auto-generated from FastAPI OpenAPI. Always run `bash scripts/generate-client.sh` after backend schema/route changes.
- **Do NOT hand-edit `frontend/src/routeTree.gen.ts`**. It is auto-generated by `@tanstack/router-plugin`.
- **State**: Server state uses `@tanstack/react-query`; UI/editing/undo state uses React hooks (`useState`, `useRef`). There is no Zustand or Redux store.
- **Formatting/Linting**: Follow `frontend/biome.json` (tabs, double quotes).
